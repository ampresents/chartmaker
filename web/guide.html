ChartMaker の使い方

ChartMaker は、レイドの作戦 (誰が、いつ、どのボスに出撃するか) を作って共有し、当日の進行を管理するためのツールです。このページではツールの仕組みと操作を説明します。ゲームのルールそのものは説明しません。

1. はじめに

作戦づくりから当日まで、次の流れで使います。

  1. 作るエディタで、プレイヤーごとの列に戦闘を並べます。自動作成も使えます。
  2. 確かめる予定スコア、到達 Lv、スタッツ、クリティカルパスを見て直します。
  3. 共有する共有URL、テキスト、チャート画像でメンバーに配ります。
  4. 当日進行管理で討伐を記録し、出撃のタイミングを全員で合わせます。
まず触ってみるなら、戦闘が 1 つもないエディタに出る サンプルを開く を押してください。架空の 20 人の作戦が読み込まれます。↶ 元に戻す で読み込む前に戻せます。

予定スコアの計算の仕組み

エディタで戦闘を動かすたびに、作戦全体をサーバーで計算し直します。各ボスの撃破時刻から、どの戦闘が何階 (Lv) で行われるかが決まり、Lv から各戦闘のスコアが決まります。そのため、1 つの戦闘を動かすと、ほかのプレイヤーの戦闘の Lv やスコアも変わることがあります。

2. エディタの画面

上部のツールバー新規、テキストを開く、元に戻す・やり直す、自動作成、スタッツ、表示の倍率、予定スコアの合計、共有URL、進行管理、画像生成。
タイムライン (中央)1 列が 1 プレイヤーです。上が開始 (0:00)、下が 60 分後です。目盛りの細い線は 1 分、黄色は 5 分、紫は 30 分ごとです。
右のパネル選択 タブには、選んだ戦闘やプレイヤーの詳細が出ます。設定 タブには、作戦全体の設定があります。テキスト タブには、作戦のテキスト版があります。パネルの幅は左端をドラッグして変えられます。

戦闘ブロックの見方

  • 色の付いた部分が戦闘で、色はボスの属性色です。その下の灰色の部分が、次に出撃できるまでのクールタイムです。
  • 文字は最大 3 行です。1 行目は戦闘の開始〜終了時刻、2 行目はボス・戦闘秒数・割合 (100% 未満のときだけ)、3 行目はその戦闘の Lv とスコアです。
  • 割合が 100% 未満の戦闘には市松模様が付きます。
  • 🔒 はロック、📝 は注意点があることを表します。紫の帯 はクリティカルパスです (7 章)。

3. 戦闘を置く・動かす

追加・選択・削除

  • 追加: 列の空いている場所をダブルクリックすると、その時刻に戦闘が入ります。
  • 選択: ブロックをクリックします。右のパネルで、ボス、開始時刻、待機時間、戦闘秒数、割合を数値で直せます。
  • 削除: 選んで Delete か Backspace を押します。
  • ボスの変更: 右クリックするたびに 1st → 2nd → 3rd → Realm と切り替わります。選んで 1〜4 を押すと直接選べます。
  • 戦闘秒数: 戦闘部分の下端をドラッグします。

ドラッグはスライドパズル

ブロックを上下にドラッグすると、隙間がある間はそのブロックだけが動きます。隣のブロックに当たると押して一緒に動かし、押されたブロックはその位置に残ります。同じプレイヤーの戦闘はクールタイムの分だけ間隔が必要なので、重なることはありません。

選んだブロックは ↑ ↓ で 1 秒ずつ、Shift を押しながらだと 10 秒ずつ動かせます。押し方はドラッグと同じです。

ロック

選んで L を押す (またはパネルのチェックを入れる) と、ブロックが固定されます (🔒、点線の枠)。ロックしたブロックはほかのブロックに押されても動かず、押す側がその手前で止まります。決まった時刻に出たい戦闘に使ってください。

スナップ (吸着)

ドラッグ中やダブルクリックで追加するときは、意味のある時刻の近くに来ると吸い寄せられ、水色の線と理由が表示されます。吸着先は次のとおりです。

  • 1st / 2nd / 3rd: ほかの列の 1st / 2nd / 3rd の開始 (同時出撃)、各階の Realm 撃破 + 余裕 (次の階が開いた時刻)
  • Realm: その階の 1st / 2nd / 3rd がすべて倒れた時刻 + 余裕

余裕の秒数は 設定 → スナップの余裕(秒) で変えられます (既定は 6 秒)。Alt を押しながらドラッグすると吸着しません。

複数選択

  • Ctrl+クリックで 1 つずつ追加・解除します。Shift+クリックで、同じ列の範囲をまとめて選びます。
  • Esc を押すか、列の空いた場所をクリックすると解除します。
  • ボスの変更、ロック、戦闘秒数、割合、削除は、選んだブロックすべてに効きます。
  • ドラッグや ↑ ↓ では、選んだブロックが間隔を保ったまま一緒に動きます。どれか 1 つがロックや端に当たると、全体が止まります。

元に戻す

Ctrl+Z で元に戻し、Ctrl+Y でやり直します。ツールバーのボタンでも同じです。サンプルの読み込み、自動作成、共有URLを開くといったまとめての変更も、1 回で戻せます。

4. プレイヤーと設定

  • 列は常に 20 人分あります。列の見出しをクリックすると、選択 タブで表示名と ID を変えたり、← 左へ 右へ → で並びを変えたりできます。
  • 名前も戦闘もない列は、作戦のテキストには書き出されません。
  • ID の末尾 2 文字を除いた部分がチーム名になります (例: Alpha01 はチーム Alpha)。チャート画像のチーム色に使われます。

設定 タブで変えられるもの:

  • 全般: コメント (画像に入る)、ゲームの開始時刻 (進行管理で使う)、スナップの余裕、クリティカルパスの強調。
  • ボス: 各ボスの属性色と、画像に表示するアイコン。アイコンはサムネイルをクリックして選びます。
  • 表示: 画像に描くもの (チーム名、ボス画像、有利属性) と、時刻を残り時間で表示するか。
  • 全体の注意点: 次の章を見てください。

5. 注意点

当日に気をつけることを作戦に書き込めます。注意点はチャート画像には描かれず、進行管理で表示・通知されます。

  • 戦闘の注意点: ブロックを 1 つだけ選び、パネルの欄に書きます。ブロックには 📝 が付きます。進行管理では、その戦闘の出撃が近づくと表示され、Discord の呼び出しにも添えられます。
  • 全体の注意点: 設定 → 全体の注意点 で、時間帯と文を指定します。タイムラインの目盛りにピンクの帯で表示されます。進行管理ではその時間帯の間だけ表示され、開始時刻に Discord へ送られます。

どちらも 1 行・200 文字までです。

6. 自動作成 β

自動作成 β を押すと、プレイヤーごとの強さから作戦の案を作ります。

  1. プレイヤーごとに、Realm を担当できる範囲と、撃破役・稼ぎ役として与えられる割合 (%) を入れます。名前のあるプレイヤーがいなければ、仮の名前で作ります。
  2. 探索時間を選んで 作成 を押します。ブラウザの中でたくさんの案を試し、いちばんスコアの高い案を選びます。中止 を押すと、そこまでの最良の案を使えます。
  3. できた案で今のブロックがすべて置き換わります (1 回の「元に戻す」で戻せます)。名前、設定、全体の注意点は残り、ロックと戦闘の注意点は消えます。

入力した強さはこのブラウザにだけ保存され、作戦には書き込まれません。できた案は出発点として、手で直して仕上げてください。

7. スタッツとクリティカルパス

スタッツ

スタッツ を押すと、作戦の分析が開きます。

  • 予定スコア、到達 Lv、戦闘数、空き枠
  • 層域 (Lv1–5、6–10 など) ごとの戦闘数とスコア
  • 予定スコアの推移のグラフ
  • 撃破後の出撃: ボスが倒れた後に出撃する予定の戦闘です。計算上はスコアに入りますが、実際には出撃できません。
  • 階ごとの撃破時刻、プレイヤーごとの出撃回数と空き枠

一覧の項目をクリックすると、そのブロックに移動します。

クリティカルパス

ボスを倒す戦闘の撃破が少し遅れたら予定スコアがどれだけ減るかを、ブロックごとに計算します。後の出撃は、進行管理と同じ規則で連鎖してずれます。

  • 10 秒の遅れでスコアが減る撃破には、紫の帯 が付きます。減り方が大きいものは太く光る帯になります。
  • ブロックにマウスを載せるかブロックを選ぶと、10 秒と 30 秒の遅れでいくら減るか、何回の出撃がずれるかが表示されます。
  • 余裕を厚くしたり、強い人を担当にしたりする候補の目安にしてください。表示は 設定 → クリティカルパスを強調する で消せます。

8. 保存と共有

自動保存編集中の作戦は、このブラウザに自動で保存されます。ページを閉じても、同じブラウザで開けば続きから編集できます。ほかの PC やブラウザには引き継がれません。
テキストテキスト タブに、作戦をテキストにしたものが出ます。テキストを保存 でファイル (日付.txt) に保存し、テキストを開く で読み込めます (進行管理の振り返りで保存した JSON も開けます)。テキストを直接書き換えて テキストを反映 で取り込むこともできます。作戦の正本はこのテキストです。
共有URL作戦をまるごと URL の中に圧縮して入れ、コピーします。受け取った人が開くと、その人のエディタに作戦が読み込まれます。作戦はサーバーに保存されません。URL が途中で切れると開けないので、全体を貼ってください。以前の (長い) 形式の共有URLも、そのまま開けます。
画像生成チャート画像 (PNG) を作ります。プレビューから PNG をダウンロード で保存できます。

9. 進行管理

当日、ボスの討伐を記録して、各プレイヤーの出撃のタイミングを全員で合わせる画面です。同じ URL を開いているすべての端末で、状態が約 1 秒ごとに同期します。作戦の開始 10 分前より前と終了 30 分後より後、および画面を隠している個人ビューでは、同期が約 10 秒ごとになります（表示し直すとすぐに同期します）。

始め方

  1. エディタで 進行管理 β を押すと、今の作戦を持って準備画面が別タブで開きます (テキストを貼り付けて始めることもできます)。
  2. 開始日と開始時刻を確かめます。開始時刻は作戦の 設定 → 開始時刻 から入ります。
  3. 必要なら Discord の Webhook URL を入れます (下の「Discord 通知」)。
  4. セッションを作成 を押すと、セッションのページに移ります。URL をコピー で、ほかの操作者に共有してください。

討伐ボタンと出撃の見込み

  • ボスが倒れたら、そのボスの討伐ボタンを押します。誤って押したら 直前の討伐を取り消す で戻せます。ボタンは今の階で押せるものだけが有効です。ほかの端末とほぼ同時に押しても、二重には記録されません。
  • 挑戦中・次に出撃: 時計ではなく、討伐ボタンの記録をもとに計算します。各戦闘の出撃見込みは、次のうち最も遅い時刻です。
    • 作戦の出撃時刻
    • 前の出撃からのクールタイム明け
    • 前に挑んだボスの撃破と、挑むボスが開く時刻 (どちらも、作戦にあった余裕の分をあけます)
    撃破が遅れれば、後の出撃も自動で後ろにずれます。待っているボスがまだ倒れていないときは「討伐待ち」「開放待ち」と表示されます。
  • 作戦との差: 撃破の遅れ (赤) や早まり (緑) です。予定スコアは、終わった戦闘の分だけを足したものです。

出撃タイマーと補正

プレイヤーごとのカードに、次に出撃できるまでの残り時間が出ます。0 になると緑の「出撃可能」に変わり、次に挑むボスが表示されます。

実際の出撃が見込みとずれたときは、カードを押して補正します。出撃可能にする で残りを 0 にでき、±1〜60 秒のボタンで残りを合わせられます。補正は全端末で共有され、そのプレイヤーの後の出撃の見込みにも反映されます。補正した戦闘には ✎ が付きます。

注意点の表示

戦闘の注意点は出撃が近づいてから戦闘中まで、全体の注意点は指定した時間帯の間、挑戦中 の上に表示されます。

Discord 通知 (任意)

  • 準備画面で Webhook URL を入れると、出撃の少し前 (既定 30 秒前) に「○○、△△、準備して下さい」を Discord に送ります。同時に出撃する人はまとめて呼びます。
  • 呼び出しは、前のボスの討伐を待たずに作戦どおりの時刻で送ります。出撃したら、そのメッセージは消されます。
  • 読み上げる (TTS) がオンなら読み上げメッセージ、オフなら普通のテキストです。読み上げを聞けるのは、PC 版の Discord でそのチャンネルを開いていて、読み上げの再生を許可している人だけです。
  • 通知は、進行管理のページを誰かが開いている間だけ送られます (サーバーは自分では送りません)。
  • 進行が大きく狂ったときは 通知を止める で全端末の通知を止められます。

作戦チャートと終了

  • ページの下に作戦のチャート画像が出ます。今の時刻の線、挑戦中 (点滅)、終わった戦闘 (暗く)、次に出撃 (点線) が重ねて表示されます。クリックすると、幅に合わせる表示と実寸が切り替わります。
  • 終わったら セッションを破棄 で消せます。すべての端末で進行管理が終わり、残っている Discord のメッセージも消えます。破棄しなくても、作成から 5 時間で自動的に消えます。

振り返り

  • ヘッダーの 振り返り で、作戦と実際の進行を比べる画面が開きます。進行中も討伐ボタンに合わせて更新されます。
  • 討伐時刻は討伐ボタンを押した時刻です。押すのが遅れた分も遅れに数えます。
  • 階ごとの表: 各階の開放時刻、ボスごとの討伐時刻と作戦との差 (遅れは赤、早いと緑)、かかった時間。
  • 遅れのグラフ: 討伐ごとの作戦との差の推移です。点にマウスを乗せると詳細が出ます。
  • 遅れが増えたボス: そのボスで新しく生まれた遅れの大きい順です。「増えた遅れ」は、討伐時の差からボスが開放された時点の差を引いたもので、前のボスから持ち越した遅れは含みません。遅れを取り戻したボスも並びます。項目をクリックすると表の該当するマスに移動します。
  • JSON で保存 で、討伐の記録と作戦をまとめてファイルに保存できます。セッションは 5 時間で消えるので、残したい記録は保存してください。
  • 保存したファイルは、進行管理の作成画面の 振り返りファイルを開く で、セッションが消えた後でも同じ振り返りとして見られます。
  • 同じファイルをエディタの テキストを開く で開くと、そのときの作戦を読み込めます (進行管理の作成画面の テキストを開く でも使えます)。作戦を直して次の回に使うときに便利です。

10. 個人ビュー

プレイヤー向けの、自分の出撃だけを大きく表示する閲覧専用の画面です。スマホでの確認に向いています。

  • 進行管理のヘッダーの 個人ビュー から、プレイヤーごとの URL を開いたりコピーしたりできます。全員分をコピー でまとめて配れます。
  • 表示されるもの: 自分の挑戦中、次の出撃までの時間、自分の戦闘の一覧、自分に関係する注意点。
  • 討伐ボタンや補正はなく、Discord 通知も送りません。進行は操作者の端末の討伐ボタンに合わせて更新されます。

11. よくある質問

作戦はどこに保存されますか？
エディタで編集中の作戦は、使っているブラウザの中だけに保存されます。ブラウザのデータを消すと消えるので、大事な作戦は テキストを保存 でファイルにも残してください。
共有URL の作戦はサーバーに残りますか？
残りません。作戦は URL の # より後ろに入っていて、この部分はブラウザからサーバーに送られません。
別の PC で続きを編集したい
共有URL を自分に送るか、テキストを保存して別の PC で テキストを開く で読み込んでください。
進行管理の URL は誰でも見られますか？
URL を知っている人だけが開けます。URL には推測できない長い ID が入っていて、それが唯一の鍵です。URL を知っている人は討伐ボタンも押せるので、信頼できる人にだけ共有してください。
進行管理のセッションはいつまで使えますか？
作成から 5 時間です。延長はできないので、次の回は新しく作成してください。
Discord の読み上げが聞こえない
PC 版の Discord でそのチャンネルを開いているか、読み上げの再生を許可しているかを確かめてください。スマホ版の Discord は読み上げません。また、進行管理のページを誰も開いていないと通知は送られません。
間違えて作戦を消してしまった
同じページで ↶ 元に戻す (Ctrl+Z) を押してください。新規作成、テキストの読み込み、自動作成なども元に戻せます。
