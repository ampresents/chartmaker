# 作戦 txt の書式

ChartMaker (`ChartLib.parse`) が読む形式。

```text
# コメント行 (# で始まる行は無視される)
::timelag=0
::1st_boss=blue
::2nd_boss=red
::3rd_boss=green
::Realm_boss=yellow
::display_party
::display_boss
::Alpha01=アリス
Alpha01,0,1st_boss,30
Alpha01,0,Realm_boss,280,0.6
```

## 定数 (`::key=value`)

- `::timelag=N`: 出撃から戦闘開始までの秒数。省略時は 0。
- `::1st_boss=` / `::2nd_boss=` / `::3rd_boss=` / `::Realm_boss=`: 各ボスの属性色。`blue` `red` `green` `yellow` `white` のどれか。**必須**。
- `::display_party` / `::display_boss` / `::display_team` / `::display_remaining`: 値なしで書くと表示が有効になる。
- `::<プレイヤーID>=<表示名>`: プレイヤーの表示名。
- `::start_time=HH:MM`: 開始時刻 (進行管理だけが使う)。

## 行動行

`プレイヤーID,待ち秒,ボス,戦闘秒[,割合][,lock|unlock[,注意点]]`

- **プレイヤーID**: `<チーム名><2 文字>` (例: `Alpha01`)。チーム名は末尾 2 文字を除いた部分。
- **待ち秒**: そのプレイヤーの前の出撃のクールタイム明け (最初の行は 0 秒) からの待ち。
  出撃時刻 = 前の出撃時刻 + timelag + 300 + 待ち秒。負にはできない。
- **ボス**: `1st_boss` `2nd_boss` `3rd_boss` `Realm_boss` のどれか。
- **戦闘秒**: 出撃してから戦闘が終わるまでの秒数 (timelag を除く)。
- **割合**: 0–1。省略時は 1.0 (倒し切る)。1 未満は、その割合だけ与えたものとして得点を数える。
  ChartMaker のエディタが書き出すテキストでは、割合を小数 2 桁以上で書く (`0` → `0.00`、`0.5` → `0.50`、`0.777` → `0.777`、`1` → `1.00`。`1.00` と省略は同じ意味)。
  半角の数 (例: `0.6`、`.5`) のときだけ割合として読む。空 (`30,,lock`) は省略と同じ。
- **lock / unlock**: 割合の次 (割合を省けば 5 項目目) に書くと、エディタでロックする / しない。大文字小文字は問わない。
- **注意点**: その後ろ、行末までの文 (カンマを含んでよい)。割合の位置が数でも `lock` / `unlock` でもなければ、そこから行末までが注意点になる。
  注意点が数や `lock` に見える文のときは、`unlock` を挟んで書く (例: `Alpha01,0,1st_boss,30,unlock,0.5`)。
- ロックと注意点はグラフには影響しない。末尾の空の項目は無視する。

例:

| 行 | 割合 | ロック | 注意点 |
|---|---|---|---|
| `Alpha01,0,1st_boss,30` | 1.0 | なし | なし |
| `Alpha01,0,Realm_boss,280,0.6` | 0.6 | なし | なし |
| `Alpha01,0,1st_boss,30,lock,最優先` | 1.0 | する | 最優先 |
| `Alpha01,0,1st_boss,30,0.5,先に,回復` | 0.5 | なし | 先に,回復 |
| `Alpha01,0,1st_boss,30,先に回復` | 1.0 | なし | 先に回復 |

同じプレイヤーの行は時刻順に並べる。プレイヤーどうしの行の順番は自由。

## コメントで書ける印 (グラフには影響しない)

- `#lock`: 直前の行動をロックする (エディタ用。以前の形式で、行末の `lock` より優先される)。
- `#note <文>`: 直前の戦闘の注意点 (以前の形式で、行末の注意点より優先される)。
- `#note@<開始秒>-<終了秒> <文>`: 時間帯の注意点。定数の後、行動行の前に書く。
