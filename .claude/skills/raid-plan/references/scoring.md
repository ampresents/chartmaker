# 得点の計算方法


## 戦闘の得点

```
基本点 = 50000 × min((Lv − 1) // 5 + 1, 5)
Realm なら × 1.2
得点 = 切り上げ(基本点 × 割合)      (割合は 0–1 に丸める)
```

| Lv | 1st / 2nd / 3rd | Realm |
|---|---|---|
| 1–5 | 50,000 | 60,000 |
| 6–10 | 100,000 | 120,000 |
| 11–15 | 150,000 | 180,000 |
| 16–20 | 200,000 | 240,000 |
| 21– | 250,000 | 300,000 |

## 予定スコア

全戦闘の得点の合計。

## 補足

- 得点の計算に用いる割合とは、ボスのHPに対する与えたダメージの量である
