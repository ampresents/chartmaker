# ゲームのルール

## 時間

- 作戦は 60 分 (0–3600 秒)。
- 1 回出撃すると、出撃から `timelag + 300` 秒は次に出撃できない (クールタイム)。
- 戦闘は出撃の `timelag` 秒後に始まり、戦闘秒だけ続く。

## 階層の進み方 (simulate.py の calc_floors)

- 各階に 1st / 2nd / 3rd / Realm の 4 体のボスがいる。
- 1st / 2nd / 3rd の 3 体が倒れた後に Realm を倒すと、次の階に進む。
- 撃破時刻は、そのボスへの戦闘のうち最も早い終了時刻。
- 1st / 2nd / 3rd への出撃は、前の階の Realm 撃破より **後** (同時は不可) でないと、その階の戦闘として数えない。
- 3 体がそろう前の Realm 戦は、前の階の Realm として数える。
- 戦闘の階層 (Lv) は、戦闘開始の時点でまだ倒れていない Realm の階。
- 出撃が 0 秒ちょうどの 1st / 2nd / 3rd は 1 階に数えない (仕様上の癖)。最初の出撃は 1 秒以降にする。

## ボスごとの性質

- ボスにはHPが設定されており、与えられたダメージの総和がHPに達すると討伐される

## プレイヤーの制約

- 1 人が同じボスに何回でも出ることはできる
